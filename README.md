# Daily Codes in C

Daily Design and Analysis of Algorithms practice programs written in C.

## Programs

- `day1.c` - Find the missing digit from 0 to 9.
- `day2.c` - Password retry loop.
- `day3.c` - Longest consecutive increasing temperature streak.
- `day4.c` - Find two array indices whose values sum to a target.
- `day5.c` - Count binary 0s, 1s, and consecutive 1s.
- `day6.c` - Generate a generalized alphabet pattern.
